实例资源申请
==========================

.. admonition:: 提示
   
   实例资源是指平台提供的预配置计算资源，用户可以直接选择所需的计算资源进行申请。实例资源包括CPU、GPU、内存等不同配置的计算资源，用户可以根据自己的需求选择合适的实例资源。

实例资源库申请可以简单分为两类：容器资源和虚拟机资源。



:wb:`容器资源`

.. raw:: html

   <hr class="divider-blue">

● 特点：平台已预装好 RStudio、PyTorch、JupyterLab 等常用科研软件。系统底层由平台统一维护，您无需（也无法） 安装驱动或修改系统配置。

● 使用方式：申请后直接通过 SSH 连接或网页图形界面开始工作。

● 适合谁： 不想折腾环境配置、希望开箱即用、专注于代码编写与数据分析的用户。

:wb:`虚拟机资源`

.. raw:: html

   <hr class="divider-blue">

● 特点：提供多个版本及类型的操作系统（如 Windows、CentOS、Rocky Linux、Ubuntu 等）。拥有 **完整的 root 管理员权限**，可自由升级内核、安装显卡驱动及任意软件，但同时也需自行负责环境的搭建与维护。

● 使用方式：申请后通过 SSH 连接或网页图形界面进入虚拟机，进行环境配置、软件安装及科研工作。

● 适合谁：需要特定系统版本、依赖底层硬件驱动、或需深度定制运行环境的进阶用户。


   💡 新手建议： 如果您刚接触平台或不确定自己的需求，请优先选择容器资源。它能帮您省去数小时的环境配置时间，让您把精力集中在科研本身；当容器无法满足您的特殊需求时，可与管理员进行沟通调整相关配置或自行申请虚拟机。

.. raw:: html

   <hr class="divider-blue">
