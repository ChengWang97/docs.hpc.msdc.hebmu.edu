***********
账号登录
***********


**前置条件**：已完成账号申请且已知晓申请人的统一身份认证账号

统一身份认证账号查询：:doc:`./..//05-faq/accountapplication/accountquery`


:black:`登录流程`
===================

.. raw:: html

    <hr class="divider_black">


申请完成的用户首先要进行atrust零信任身份认证平台下载，下载完成后进行配置登录。

.. raw:: html

   <p>访问官网：</p>
   <p><a href="https://msdc.hebmu.edu.cn/"
      target="_blank"
      rel="noopener noreferrer">
      医学科研数据中心
   </a></p>

点击【登录入口】即可跳转到医学科研数据中心atrust下载界面。

.. figure:: /_static/img/accountLogin/accountLogin-1.png
   :alt: 登录跳转
   :width: 100%
   :class: zoomable

步骤2：在atrust下载界面，点击“立即下载”，下载完成后，点击“立即安装”。
   
   （系统会根据您的电脑操作系统自动适配对应的软件版本，以下是电脑为windows操作系统范例）

.. figure:: /_static/img/accountLogin/accountLogin-2.png
   :alt: 登录跳转
   :width: 100%
   :class: zoomable


.. figure:: /_static/img/accountLogin/accountLogin-3.png
   :alt: 登录跳转
   :width: 100%
   :class: zoomable

步骤3：atrust客户端安装完成后，跳出“接入设置”，输入接入地址https://msdcvpn.hebmu.edu.cn/   ，点击确认接入。

.. figure:: /_static/img/accountLogin/accountLogin-4.png
   :alt: 登录跳转
   :width: 100%
   :class: zoomable

步骤4：在atrust客户端登录界面，点击【前往浏览器登录】，跳转到统一身份认证账号登录界面。

.. figure:: /_static/img/accountLogin/accountLogin-5.png
   :alt: 登录跳转
   :width: 100%
   :class: zoomable

步骤5：统一身份认证平台【用户名登录】，输入学校赋予您的工号/学号和密码。

.. figure:: /_static/img/accountLogin/accountLogin-6.png
   :alt: 登录跳转
   :width: 100%
   :class: zoomable

步骤6：登录atrust成功界面显示如下，点击“高性能计算平台”进入计算平台界面，选择“统一身份认证登录”即可登录。

.. figure:: /_static/img/accountLogin/accountLogin-7.png
   :alt: 登录跳转
   :width: 100%
   :class: zoomable

弹出高性能计算平台登录界面，通过点击通过统一认证服务登录按钮进行登录

   首次登录高性能平台需要重置高性能平台的密码，此密码为平台登录密码，仅供ssh集群、ssh实例登录使用，非统一身份认证密码。请牢记新密码。

.. figure:: /_static/img/accountLogin/accountLogin-8.png
   :alt: 登录跳转
   :width: 100%
   :class: zoomable


忘记密码
====================

重置统一身份认证登录密码
------------------------------

统一身份认证登录密码可通过云上冀医app重置修改

.. figure:: /_static/img/accountLogin/accountLogin-9.png
   :alt: 登录跳转
   :width: 100%
   :class: zoomable




重置高性能平台登录密码
------------------------------

在高性能平台需使用ssh工具登录集群或登录实例，使用右上角“重置密码”功能。

.. figure:: /_static/img/accountLogin/accountLogin-10.png
   :alt: 登录跳转
   :width: 100%
   :class: zoomable
